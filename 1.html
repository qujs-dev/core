Обзор Qu.Liker

Qu.Liker — это плагин для организации голосований, рейтингов и оценок на веб-страницах. Он предоставляет готовые UI-компоненты с различными типами взаимодействия: лайки, звёздный рейтинг, эмодзи-реакции и «пальцы вверх/вниз».

Плагин умеет сохранять голоса пользователей в localStorage, синхронизировать состояние между вкладками через BroadcastChannel и отправлять данные на сервер для постоянного хранения.

Основные возможности

  • 4 типа голосования:
    • like — классический лайк (кнопка + счётчик).
    • stars — звёздный рейтинг (от 1 до 5 звёзд).
    • emoji — выбор эмодзи с выпадающей палитрой.
    • thumbs — оценка «пальцем вверх/вниз».
  • Сохранение состояния: голоса пользователей хранятся в localStorage.
  • Синхронизация между вкладками: через BroadcastChannel.
  • Интеграция с сервером: отправка голосов на сервер через POST-запрос.
  • Поддержка капчи: защита от спама (опционально).
  • Гибкая настройка через глобальный конфиг и data-* атрибуты.
  • Кастомизация через CSS-переменные: можно полностью изменить внешний вид.
  • Уведомления: через Qu.Notifyer (или fallback на alert и свою реализацию).

Структура данных

Плагин использует следующие ключевые поля для идентификации голосования:

  • target_id — ID объекта (например, ID записи).
  • target_key — строковый ключ (например, 'post').
  • type — тип голосования ('like', 'stars' и т.д.).
  • tag — дополнительный тег для группировки.

Эти поля формируют композитный ключ, по которому сохраняется голос пользователя в localStorage.

💡 Совет

Используйте Liker для любых элементов, где требуется обратная связь от пользователя: посты, комментарии, товары, фотографии. Плагин легко адаптируется под любой дизайн через CSS-переменные.

Подключение (рекомендуемый способ)

Самый простой и надёжный способ — подключить плагин через ядро Qu. Ядро автоматически зарегистрирует плагин через Qu.lib(). 

<!-- Подключаем плагин Liker -->
<script src="https://cdn.jsdelivr.net/gh/qujs-dev/liker@latest/liker.min.js" async></script>
 
<!-- Подключаем ядро Qu + загрузчик Que где-то сверху -->
<script src="https://cdn.jsdelivr.net/gh/qujs-dev/core@latest/qu.min.js" defer></script>
 
<!-- инициализируем плагин -->
<script>
Que(function() {
    Qu.libs(["Liker"], {
        autoInit: true,
        initParams: {
            Liker: {
                action_url: '/api/vote',
                // ... остальные настройки
            }
        }
    }).then(({ Liker }) => {
        console.log('Liker загружен');
    });
});
</script>

После регистрации плагин становится доступен как Qu.Liker.

⚠️ Важно

Для работы плагина обязательно укажите action_url — эндпоинт на сервере, который будет обрабатывать голоса. Без этого плагин не сможет сохранять данные на сервере.
Серверная часть не включена в плагин.

Data-атрибуты элементов

Все настройки можно задавать прямо в HTML через data-qu-liker-* атрибуты. Это позволяет создавать разные голосования с уникальными параметрами.

АтрибутЗначениеНазначение
data-qu-liker true Активирует плагин на элементе.
data-qu-liker-type 'like', 'stars', 'emoji', 'thumbs' Тип голосования.
data-qu-liker-target-id число или строка ID объекта (например, ID поста).
data-qu-liker-target-key строка Ключ объекта (например, 'post').
data-qu-liker-tag строка Дополнительный тег.
data-qu-liker-action-url URL Переопределяет глобальный action_url.
data-qu-liker-max число Максимальное количество звёзд (для типа stars).
data-qu-liker-current число Начальное значение (текущий рейтинг).
data-qu-liker-total число Начальное количество голосов.
data-qu-liker-inherit true / false Наследовать параметры от родительского элемента (по умолчанию true).
data-qu-liker-use-grecaptcha true / false Включает reCAPTCHA для этого элемента.
data-qu-liker-field строка (путь к полю в ответе) Обновляет содержимое элемента из данных ответа сервера.

Типы голосования

Плагин поддерживает 4 встроенных типа. Вы можете зарегистрировать свои через Qu.Liker.registerType().

1. like — классический лайк

  • Одна кнопка, по клику добавляется +1 к счётчику.
  • При повторном клике снимается лайк.
  • UI: кнопка с иконкой и счётчиком.

Атрибуты:

  • data-qu-liker-btn="like" — кнопка лайка.
  • data-qu-liker-field="total_likes" — отображение количества лайков.

2. stars — звёздный рейтинг

  • Выбор от 1 до max звёзд.
  • Отображает средний рейтинг и количество голосов.
  • Поддерживает дробные значения (например, 4.5).

Атрибуты:

  • data-qu-liker-stars-container — контейнер со звёздами.
  • data-qu-liker-star — каждая звезда.
  • data-qu-liker-field="avg_rating" — средняя оценка.
  • data-qu-liker-field="total_votes" — количество голосов.

3. emoji — реакции эмодзи

  • Отображает текущий выбранный эмодзи.
  • При клике открывается палитра с вариантами.

Атрибуты:

  • data-qu-liker-emoji-trigger — кнопка, открывающая палитру.
  • data-qu-liker-emoji-palette — контейнер с вариантами эмодзи.
  • data-qu-liker-emoji-value — каждый вариант эмодзи (значение).

4. thumbs — «пальцы вверх/вниз»

  • Две кнопки: 👍 и 👎.
  • Отображает сумму голосов (разницу).

Атрибуты:

  • data-qu-liker-btn="thumbs-up" — кнопка «вверх».
  • data-qu-liker-btn="thumbs-down" — кнопка «вниз».
  • data-qu-liker-thumbs-class — класс для отображения результата.

Qu.Liker.registerType(typeName, handler)

Регистрирует новый тип голосования.

Сигнатура

Qu.Liker.registerType('myType', { initUI, handleClick, updateUI, setVotedState })

Параметры

Объект-обработчик может содержать методы:

  • initUI(instance) — инициализация UI.
  • handleClick(instance, target, event) — обработка кликов.
  • handleVote(instance, value) — обработка голоса.
  • updateUI(instance, data) — обновление UI после голосования.
  • setVotedState(instance, userValue) — установка состояния «проголосовано».

Пример

Qu.Liker.registerType('color', {
    initUI(inst) {
        inst.picker = inst.element.querySelector('[data-qu-liker-color-picker]');
        inst.picker?.addEventListener('change', () => {
            inst._vote(inst.picker.value);
        });
    },
    handleVote(inst, value) {
        inst._vote(value);
    },
    updateUI(inst, data) {
        inst.element.style.backgroundColor = data.color;
    }
});

Qu.Liker.syncFromServer()

Синхронизирует локальное хранилище с сервером. Отправляет запрос на action_url с параметром action=total и обновляет все голоса.

Сигнатура

Qu.Liker.syncFromServer()

Возвращаемое значение

Promise, который разрешается с объектом голосов с сервера.

Пример

 
// Синхронизация при загрузке страницы
Que(function() {
    Qu.libs(['Liker'], { autoInit: true }).then(() => {
        return Qu.Liker.syncFromServer();
    }).then(votes => {
        console.log('Голоса синхронизированы', votes);
    });
});

Qu.Liker.debug(...args)

Выводит отладочные сообщения, если включён режим _debug (так же можно включить через ?_qu-liker-debug=1).

Сигнатура

Qu.Liker.debug(message, ...args)

Параметры

Аналогичны console.log.

liker:beforeVote

Генерируется на элементе голосования перед отправкой запроса на сервер.

Детали события (event.detail)

ПолеТипОписание
instanceobjectЭкземпляр Liker.
valueanyЗначение голоса.
mutatebooleanВсегда true.

Пример

Qu.on('liker:beforeVote', '[data-qu-liker]', function(e) {
    var instance = e.detail.instance;
    instance._rawParams.somevalue = 'дополнительный параметр';
});

liker:afterVote

Генерируется после получения ответа от сервера.

Детали события (event.detail)

ПолеТипОписание
instanceobjectЭкземпляр Liker.
responseobjectОтвет сервера.
mutatebooleanВсегда true.

Пример

document.addEventListener('liker:afterVote', function(e) {
    if (e.detail.response.success) {
        console.log('Голос учтён!');
    }
});

liker:beforeInit

Генерируется перед инициализацией плагина (на document.body).

Детали события (event.detail)

ПолеТипОписание
QuobjectЭкземпляр Qu.
LikerobjectКонструктор Liker.

Тип emoji – реакции эмодзи

Выбор одного эмодзи из выпадающей палитры. Поддерживает отображение статистики по каждому эмодзи.

Основные атрибуты:

  • data-qu-liker-type="emoji"
  • data-qu-liker-emoji-trigger – кнопка, открывающая палитру
  • data-qu-liker-emoji-palette – контейнер с вариантами
  • data-qu-liker-emoji-value – каждый вариант (значение)
  • data-qu-liker-emoji-current – отображение текущего выбранного эмодзи

  • data-qu-liker-field="stats.{value}" – количество голосов за конкретный эмодзи

Тип thumbs – «пальцы вверх/вниз»

Две кнопки: 👍 и 👎. Отображает разницу голосов (score) и количество лайков/дизлайков.

  • data-qu-liker-field="total_likes" – количество лайков
  • data-qu-liker-field="total_dislikes" – количество дизлайков

CSS-переменные для кастомизации

Все стили Liker построены на CSS-переменных, что позволяет легко адаптировать внешний вид под любой дизайн. Вы можете переопределить любую переменную глобально (например, в :root) или локально на контейнере [data-qu-liker].

Для удобства встроены готовые темы: default, borders, borders-dark, dark. Их можно применить через атрибут data-qu-liker-theme="borders".
